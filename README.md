# Desafio Banco Carrefur

Este desafio é proposto pela **Verx** a pedido do **Banco Carrefur** para avaliação de candidatos a vaga de *Arquiteto de Soluções*. O texto original do desafio está em: [Desafio]("docs/desafio.pdf").

Para exemplificar, vamos utilizar a empres **Fernandes Mecânica**, uma empresa de manutenção em máquinas e venda de peças, que tem 3 lojas no estado de Goiás, uma em Rio Verde (matriz), outra em Anápolis e outra em Águas lindas de Goiás. Cada loja tem um **Caixa**, um **Auxiliar Administrativo**.
